# dotfiles

My personal dotfiles. This is mainly targeted towards Fedora w/ GNOME, but mostly supports
MacOS as well (with the caveat that things like the fonts need to be configured differently).

## Included Configurations/Tools

- Fully prepared NeoVim configuration combining the aspects of VSCode that I enjoyed
  with fixes and tooling for the areas I despised.
- Bash configuration + non-specific aliases I use across all of my systems.
- Tmux configuration
- Agent configurations for Codex, Copilot, and Claude
- Tools and scripts I use on a daily basis for tasks like profiling, debugging, and general development.
- Terminal configuration for Tabby.
- Node package management used across the aforementioned various tools and scripts.
- Devcontainer configuration tooling for quickly spinning up a development environment with 
  the above tooling pre-installed.
